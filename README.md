
# RPG Files

This repository exists to preserve backup copies of the files from the
`dnd-dm-helper` and `dnd-player-helper` projects in a separate location.

## Contents

- `dnd-dm-helper/`: backups and data for the Dungeon Master helper;
- `dnd-player-helper/`: backups and data for the player helper.

These files are backup copies and may not represent the latest state or a
ready-to-run version of the original projects.

## Public versions

- [D&D DM Helper](https://dnd-dm-helper.vercel.app/home/homebrew)
- [D&D Player Helper](https://dnd-player-helper-5e.vercel.app/play)
