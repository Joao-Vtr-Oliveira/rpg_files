
# Atronos Forge Files

This repository exists to preserve backup copies of the files from the
`atronos-forge-dm` and `atronos-forge-player` projects in a separate location.

## Contents

- `atronos-forge-dm/`: backups and data for Atronos Forge DM;
- `atronos-forge-player/`: backups and data for Atronos Forge Player.

These files are backup copies and may not represent the latest state or a
ready-to-run version of the original projects.

- [Atronos Forge DM](https://atronos-forge-dm.vercel.app/home)
- [Atronos Forge Player](https://atronos-forge-player.vercel.app/play)
